# plusコマンド

![test](https://github.com/Riku37700606/robosys2026/actions/workflows/test.yml/badge.svg)

標準入力から読み込んだ数字を足すコマンドです。

## ダウンロード方法

```bash
git clone https://github.com/Riku37700606/robosys2026.git
cd robosys2026
```

## 使い方

```bash
seq 5 | ./plus
```

実行結果

```
15
```

## 必要なソフトウェア

- Python
  - テスト済みバージョン: 3.10〜3.14

## テスト環境

- Ubuntu 24.04 LTS
